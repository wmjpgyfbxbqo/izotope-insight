## Overview

iZotope Insight 2 is a comprehensive metering suite providing loudness, dynamic range, spectrogram, phase correlation, and true peak analysis for broadcast-compliant audio delivery.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Izotope Insight** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **LUFS Metering** | Integrated, short-term, and momentary LUFS per EBU R128 and ATSC A/85 |
| **Spectrogram** | High-resolution time-frequency spectrogram for identifying artifacts |
| **Tonal Balance** | Tonal Balance Control links to other iZotope plugins for guided EQ |
| **Surround Support** | Up to 7.1 surround metering for film and broadcast workflows |
